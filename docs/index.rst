EirinMath: C++20 Fixed-Point, Vector and Matrix Arithmetic Library
====================================================

**EirinMath** is a flexible and high-performance C++ arithmetic library, which provides fixed point template class, high precision mathematical operations, basic input and output functions, saturating arithmetic functions, vector library and matrix library.
